# A media family you can explain

A media derivative should keep its source, version, transformation, contributors,
claim changes, rights, accessibility, and evaluation references together. Each
format should add a useful affordance for an identified audience and job.

The source design asks whether another person can find the origin, understand
what the new format adds, and reuse the family without an oral explanation.

This agent-written candidate summary compresses Multimedia Multipliziert. It
omits the full production procedure, component list, and eleven-surface catalog.
It is provided as an alternative to the action-oriented source-first card.
