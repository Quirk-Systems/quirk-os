# Quirk Five-M — candidate build brief

**Version:** v0.1-candidate · **Status:** candidate · **Owner:** Bryan (human gate)
**Phrase:** Move / Money / Merge / Monitor / Machine

## Problem and first useful result

Quirk can generate code, content, ideas and activity faster than Bryan can verify which work matters. A large automation surface can amplify low-value work, fake proxy gains, or expensive maintenance.

The Five-M candidate returns **one bounded next-action record** with a beneficiary, verified goal, evidence basis, constraint, allowed action, cost and attention budget, stop condition, and human gate. It does not promise exponential earnings.

## Preserve the distinctive mechanism

**Make moves that produce evidence. Make money from actual value. Merge only what is proven. Monitor what matters. Machine only what is authorized.**

The five views describe one decision—not five separate agents or new permission systems.

## First slice

One read-only work card: the current blocker, the cheapest action, real outcome metric, review prerequisite, monitor condition, and proposed automation boundary. No new spend.

### Example A — project progress

For `Quirk-Systems/quirk-os#62`, Move = inspect exact-head gate; Money = quantify wasted human correction time (not invent savings); Merge = HOLD while hosted checks have not executed; Monitor = check runner eligibility; Machine = produce candidate validation receipts without bypassing authority.

### Example B — legitimate revenue hypothesis

A permissioned Quote Rescue trial could test whether a single business improves its inquiry follow-up. Interest in a price is **not revenue**; payment received is revenue. Start from one consented anonymized example and a preregistered outcome measure. No unsolicited outreach, customer-data ingestion, or pricing/publishing automation is authorized by this brief.

## User journey

1. Submit a work item or chaotic idea.
2. The card exposes five lenses and marks absent evidence `UNKNOWN`, not zero or pass.
3. The user chooses or rejects a single proposed next move. The card records the decision but never executes a higher-impact action without a separate exact grant.

**Empty/error behavior:** missing source → SOURCE_UNAVAILABLE; stale revision → NEEDS_RECHECK; permissions unknown → HOLD; metrics lack real outcomes → NOT_PROVEN.

## Exclusions

No runtime agent, provider integration, paid action, automated merge, auto-deployment, unsolicited contact, durable preference update, publication, or Quirk canon promotion.
