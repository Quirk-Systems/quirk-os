# Five-M First Proof — 30-minute proposed bound

This is a pilot plan, not a completed experiment.

1. **Source (5 min):** choose one Quirk PR/issue with a fresh exact source revision and a consequential blocker.
2. **Move (5 min):** identify one cheapest reversible next action and stop condition.
3. **Money (5 min):** record actual human minutes, variable cost, and whether any real beneficiary/revenue outcome is evidenced. If absent, mark NOT_PROVEN.
4. **Merge / Monitor (5 min):** inspect exact-head checks, reviewer status, key signal, and feedback delay. Explain HOLD if CI cannot execute.
5. **Machine (5 min):** identify one safe candidate-only step worth automation; specify read/write scope, approval, rollback, and failure receipt.
6. **Human test (5 min):** Bryan or one independent reviewer explains what happens next, why, and what is not authorized.

**Proposed pass condition:** reviewer correctly states the next action, source, blocker, value evidence, and authority boundary within three minutes; no invented revenue, no implied CI pass, no permission leap; preparation + correction ≤15 human minutes after the first setup. If not, revise the card.

**Cheapest disproof:** compare a plain PR summary against the Five-M card; if the card adds no better decision and increases review burden, drop the extra structure.

**Decision:** KEEP / MUTATE / DROP, with a dated observation receipt. No user-invisible score or automatic promotion.
