# Five-M Next Move — candidate

Return a **single One Move Card** using Move / Money / Merge / Monitor / Machine.

1. Begin with the real beneficiary and one intended outcome.
2. Ground source revision, baseline, metric and counter-metric; distinguish observed from inferred.
3. Select the cheapest reversible Move with an owner and stop condition.
4. Money: recognize received payment or observed value only; never inflate proxies.
5. Merge: require exact-head checks and scoped human authorization.
6. Monitor: request updates only for meaningfully changed evidence.
7. Machine: keep new automation read-only or candidate-draft unless explicit grants exist.
8. End with a review packet and an evidence receipt. This skill cannot promote itself.

Do not spend, deploy, post, merge, contact others, persist personal preference, or widen authority from this skill alone.
