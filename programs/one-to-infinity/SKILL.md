# One-to-Infinity
Version: `0.2.0-candidate` · Status: candidate-only.

Modes: `shape`, `audit`, `prove`, `package`.

1. Name the beneficiary outcome before automation.
2. Separate value, retention, closure, scalability, and compounding.
3. Require retained state to change a later cycle.
4. Require preregistered matched comparison or ablation before compounding claims.
5. Treat proxies and benchmarks as diagnostics, not beneficiary value.
6. Respect constraints, balancing forces, and feedback delays.
7. Learning remains candidate until a human explicitly authorizes reuse.
8. Infrastructure executes or projects state; it does not confer semantic authority.
9. Deterministic rules belong in schemas and validators.
10. Stop at a review packet. This skill never promotes itself.

Boundary: no runtime, provider access, publication, autonomous promotion, or canon promotion.
