# Authority Topology

| Move | Beauty | Quirk core | Provider projection |
|---|---:|---:|---:|
| Define beauty-specific comparison semantics | owns | registers/adjudicates | mirrors only |
| Capture explicit choice or outcome | proposes/captures | authorizes storage policy | stores bounded event |
| Derive evidence or rank candidate | computes | audits policy | may execute pure code |
| Explain recommendation | supplies locked envelope | grants model action | renders only |
| Approve graph update | no | human gate owns | no |
| Apply graph update | no | Preference Graph service owns | mirrors receipt only |
| Publish, message, purchase | no implicit authority | explicit effect grant required | executes only within grant |
| Admit canon | no self-promotion | repository governance owns | no |

**Invariant:** reachability is not permission; capability is not authority; technical success is not admission.
