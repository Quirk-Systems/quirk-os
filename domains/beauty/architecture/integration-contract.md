# Integration Contract

## Truth hierarchy

```text
Git boundary definition
  > Quirk core authority decision
  > Quirk core evidence receipt
  > explicit human choice/outcome
  > deterministic Beauty candidate output
  > provider-rendered explanation
  > Supabase/Airtable projection
  > analytics or engagement signal
```

A lower layer cannot overwrite a higher one.

## Provider contracts

### GitHub

Owns reviewable bytes and exact-SHA decisions. A branch or PR is candidate evidence; merge is a separate human effect.

### Supabase

Stores a reproducible private projection. It cannot issue authority or write canonical definitions. Derived rows are service-written; human rows are limited to explicit choice and outcome events.

### Airtable

Provides pilot operations and review visibility. Only whitelisted operational notes are editable. Sync order never decides truth.

### Cloudflare

Provides a disabled-by-default request boundary. It delegates grant verification and explanation rendering to separate services. No provider key is committed or exposed to the browser.

### OpenAI

Renders a structured explanation from a locked recommendation envelope. It cannot change rank, evidence, confidence, authority, or state.

## Failure policy

Every provider may disappear without changing the domain boundary. Loss of a projection may impair convenience, but it must not erase canon, consent, decisions, or receipts.
