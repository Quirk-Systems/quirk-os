# Integration Boundaries

## Product Design

Owns the interaction evidence: comprehensible choices, visible uncertainty, outcome capture, and the Human Gate review surface. It does not decide preference truth.

## Sales

Owns the design-partner hypothesis, proof-to-offer translation, and commercial falsification criteria. It cannot transform one proof into a market claim.

## Superpowers workflow

The pack is organized for test-first implementation, explicit planning, independent review, and verification before completion. Automated tests are necessary; the real-world proof is the final non-automatable gate.

## Supabase

Provides a candidate runtime projection with RLS and append-only event tables. It does not own canon or the authoritative Preference Graph.

## GitHub

Provides Git-backed review, CI, diffability, ownership, evidence attachments, and admission history. A merged canonical boundary must remain a separate review concern from candidate runtime code.

## OpenAI Developers

OpenAI integration is restricted to an optional structured explanation renderer after the deterministic rank exists. The model receives only cited factors and returns a schema-constrained explanation. It cannot rank, mutate, publish, or infer outcomes.

## Hugging Face

Hugging Face is reserved for de-identified evaluation dataset packaging and reproducible model comparisons after explicit approval. No private preference evidence is uploaded in v0.1.
