# Human Gate Checklist

- [ ] I saw the exact recommendation and its evidence before testing it.
- [ ] I tested the recommended option in the declared real-world context.
- [ ] The outcome record reflects my explicit judgment, not a click or purchase event.
- [ ] The proposed Preference Graph changes are visible feature by feature.
- [ ] The proposal affects only my actor ID and declared purpose partition.
- [ ] The proposal has not expired and references the current graph revision.
- [ ] I choose **approve**, **revise**, or **reject** deliberately.
- [ ] Any correction replaces the relevant inferred value rather than being silently averaged into it.
- [ ] A receipt will record the exact effect.
- [ ] I understand that this decision does not authorize publishing, purchasing, messaging, cross-purpose reuse, or canon promotion.
