# Quirkverse Activation Engine — Candidate v0.1

## Doctrine

> The Quirkverse does not decorate the work. It metabolizes the work.

A signal is not merely summarized. It is routed into a living system of residents, locations, story pressure, formats, capability pursuits, governed moves, artifacts, evidence receipts, and continuity deltas.

```text
SIGNAL
→ WORLD ROUTING
→ CAST
→ LOCATION
→ STORY PRESSURE
→ FORMAT
→ CAPABILITY PURSUIT
→ GOVERNED MOVE
→ ARTIFACT
→ EVIDENCE RECEIPT
→ WORLD-STATE CHANGE
```

This package is **candidate-only**. It does not authorize runtime execution, lore promotion, Canon change, publication, deployment, financial action, physical action, or external-system mutation.

## Structural opportunity

Quirk already separates signal, decision, capability, authority, execution, evidence, memory, and Canon. Narrative Systems adds a disciplined way to make those mechanics memorable, participatory, and reusable without allowing story logic to impersonate operational authority.

The Activation Engine is the boundary between:

- the outside event that creates pressure;
- the Quirkverse format that stages the pressure;
- the system artifact that addresses the pressure;
- the evidence that decides what survives;
- the continuity update that records only what the evidence earned.

## Activation formats

| Format | Mechanics | Proof it must leave |
| --- | --- | --- |
| Resident Dispatch | Route work to a perspective with bounded authority | Decision, architecture, performance artifact, or contradiction map |
| Character Encounter | Preserve productive disagreement between residents | Tradeoff record and named disposition |
| Location Event | Change a location only when the event earns it | Location-state delta and evidence |
| Quest / Bounty | Bounded objective, constraints, proof, reward, failure | Quest artifact and completion receipt |
| Tournament / Challenge | Compare candidates under one frozen rubric | Scoreboard, reviewer, fixtures, winner disposition |
| Design Tribunal | Admit, revise, hold, split, reject, or preserve | Evidence-backed admission record |
| Town Hall / Broadcast | Translate a system change into shared understanding | Communication artifact and comprehension/action receipt |
| Museum Exhibit | Preserve failure, retirement, or lineage without promotion | Exhibit, scar, sources, explicit non-authority |
| Merchant Drop | Convert a capability into a bounded commercial object | Offer, proof, rights, limits, buyer evidence |
| Performance / Playable Release | Turn signal into authored experience and participation | Experience, authorship/provenance, audience receipt |
| World Patch Notes | Preserve continuity across adds/changes/removals | Before/after state and authority effect |

Additional bounded projections may include Teams Work Receipts, Skill Trials, and Capability Admission hearings.

## Lifecycle and dispositions

```text

→ PROPOSAL
→ CANDIDATE

```

Alternative outcomes:


A winner does not self-promote. Popularity does not imply Canon. A score requires a frozen rubric and named reviewer. A world-state change requires evidence and explicit human approval.

## Wins, losses, and open-world continuity

### Win

A win means the artifact survives:

1. authority review;
2. frozen rubric or acceptance test;
3. adversarial fixtures;
4. independent verification;
5. outcome review;
6. continuity-delta approval.

A win may earn a transition to `TESTED` or `ADMITTED`. It does not automatically earn Canon.

### Loss

A loss is preserved when it reveals a constraint, broken assumption, taste scar, authority problem, or invalid bet.

A useful loss produces:

- failure receipt;
- cheapest-disproof result;
- boneyard or lineage disposition;
- one reusable fixture, rule, or exhibit;
- explicit non-promotion.

### Open world

Open-world entries remain unresolved and queryable:

- watched locations;
- active resident tensions;
- live quests;
- stalled capability pursuits;
- unjudged candidates;
- context windows nearing expiry;
- recent changes awaiting outcome evidence.

Open-world state is runtime/contextual state, not Canon.

## Context windows

A contextual window should include:

- window ID and purpose;
- relevant residents and locations;
- active storylines;
- recent changes;
- wins, losses, and unresolved bets;
- current capability pursuits;
- evidence links;
- expiry or refresh trigger;
- explicit statements that are not authoritative.

Memory preserves context. Evidence and human decision determine truth and authority.

## Adversarial doctrine

The engine must reject:

1. spectacle without substance;
2. lore promoted as evidence;
3. character popularity mistaken for authority;
4. competition with no credible rubric or reviewer;
5. artifact produced without real outcome;
6. story twist hiding a scope or authority change;
7. platform projection promoted into canonical state;
8. generated volume mistaken for authored value;
9. candidate location mistaken for admission;
10. self-certified world-state change.

## Projection model

Git holds candidate contracts and evidence definitions. Other systems are projections:

- **Quirk Town** — residents, locations, quests, events, and open-world state.
- **Quirk Memory** — contextual windows, retrieval, recency, and expiry.
- **Quirk Skills** — reusable compiler/activation skill candidate.
- **Quirk Music** — performance, track ritual, playable release, authorship/provenance.
- **Airtable** — operational registry and review views.
- **Notion / Google Drive** — knowledge and collaboration surfaces.
- **Slides / diagrams / product UI** — disposable visual projections.

No projection may silently become canonical or expand authority.

## Smallest admissible proof

Run one real signal through two different activation formats under a frozen rubric. Require:

- one operational artifact;
- one receipt;
- five adversarial fixtures;
- one win or loss disposition;
- one approved world-state delta or explicit no-change;
- an independent reviewer who did not author the activation.

The concept fails if the narrative layer adds ceremony without improving memory, judgment, participation, proof quality, or reuse.
