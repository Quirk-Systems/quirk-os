# Project Instructions Canon Candidate

A project instruction pack exists to make a project resumable without the original operator standing nearby.

## Required content

- outcome;
- non-goals;
- current state;
- source authority;
- object grammar;
- actors and ownership;
- authority;
- stack and dependencies;
- interfaces;
- data and privacy;
- execution routes;
- tests and evaluations;
- release and rollback;
- open decisions;
- next executable Move.

## Context loading

Load the smallest set of project instructions required for the current task. Do not inject an entire project archive when a bounded contract is sufficient.

## Completion test

Another qualified human or agent should be able to continue, evaluate, or safely stop the project without requiring invisible interpretation.
