# Optimized Settings Canon Candidate

## Settings grammar

```text
Default
< admitted global setting
< admitted purpose setting
< current session setting
< current explicit instruction
```

Higher precedence does not create new authority; it selects among already permitted behaviors.

## Core setting groups

### Personalization

- enabled;
- purpose partition;
- adaptation mode;
- implicit-signal policy;
- preference decay;
- used-preference visibility;
- generated-UI permission;
- exploration permission.

### Expression

- verbosity;
- directness;
- challenge;
- humor;
- profanity;
- novelty;
- emotional intensity;
- evidence density.

### Runtime

- model route;
- tool availability;
- cost and latency budget;
- retry and timeout;
- privacy mode;
- local or remote processing.

### Authority

- memory updates;
- settings changes;
- protected actions;
- deployment;
- financial or legal commitments;
- impersonation.

## Optimization doctrine

Optimize for accepted, reusable outcomes per unit of human attention. Do not optimize merely for engagement, response length, or agent activity.
