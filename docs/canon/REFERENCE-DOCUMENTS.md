# Custom Reference Documents Canon Candidate

## Reference types

- canonical specification;
- candidate specification;
- primary external source;
- research synthesis;
- example;
- negative example;
- dataset;
- media reference;
- decision record;
- run receipt;
- superseded history.

## Reference requirements

Every durable reference records identity, source, date, purpose, authority, rights, freshness, supported claims, contradictions, and content hash.

## Retrieval

Reference selection must consider:

```text
purpose relevance
× source authority
× freshness
× evidence quality
× rights
× sensitivity
× contradiction coverage
```

Popularity and retrieval convenience are not authority.

## Imported terms

Imported vocabulary remains mapped and provenance-linked until separately admitted into Quirk Canon.
