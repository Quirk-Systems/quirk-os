# Custom Instructions Canon Candidate

## Distinctions

| Instruction class | Scope | Authority |
| --- | --- | --- |
| Current instruction | Current task or turn | Highest personalization precedence |
| Project instruction | Named project | Admitted project scope |
| Platform instruction | Platform behavior | Transport and interface constraints |
| Purpose-scoped preference | Named purpose | Expression and workflow guidance |
| Global preference | Cross-purpose tendency | Lowest durable personalization layer |
| Inference | Candidate interpretation | Proposal only |

## Requirements

Custom Instructions must be:

- inspectable;
- editable;
- purpose-scoped where possible;
- versioned when durable;
- separable from factual memory;
- unable to grant protected authority;
- testable with negative examples;
- removable without destroying user-owned work.

## Prohibited patterns

- permanent persona assignment;
- sensitive trait inference without consent;
- hidden cross-purpose leakage;
- model confidence treated as user intent;
- stylistic preference overriding truth or accessibility;
- instructions that require invisible owner interpretation at runtime.
