# Bounded prompt-engineered improvement

Use these prompts against the exact candidate revision. Reference files and failing cases; do not invent evidence. Each round emits findings, patch, regression results, hashes, remaining gaps, and status CANDIDATE.

## Round 1 — Compose

“Inspect existing contracts and source revisions. Build the smallest crossing that retains creative medium, capability ecosystem, and participatory world. Trace each output to source, domain meaning, authority, and intended audience. Identify what is merely proposed. Preserve local work and frozen contracts.”

## Round 2 — Break

“Attack the crossing with private data, unknown rights, stale revisions, conflicting sources, unknown versions, duplicate keys, non-finite values, unsupported domains, self-promotion, edited generated files, and partial write failures. Produce counterexamples. Repair evidenced failures without weakening the checks.”

## Round 3 — Earn

“Execute the example from the README as a new operator would. Compare source and output meaning, replay digests, rollback, maintenance burden, and creative possibility. Keep untried futures visible. Separate machine passage from human preference and live host behavior. Patch only supported defects; stop when the slice passes or remains blocked.”

Stop after three material rounds; earlier if the slice passes with no critical open defects. Persistent failure leaves a candidate and a precise next Move. Never change acceptance thresholds, authority, fixture expectations, or canon to manufacture success. Human silence is not approval. This file describes a manual method; it installs no agent or recurring loop.
